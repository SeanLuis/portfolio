## About Berea AI

Berea is an upcoming knowledge agents platform inspired by the Bereans of Acts 17:11: every answer should be easy to examine. Administrators create workspaces, define specialized agents, upload documents with ACL, and let teams ask questions via a web console, embeddable widget, or connected channels — always with citations to the source document and page.

**Status: Coming Soon.**

## Responsibilities & Contributions

- **Agents grounded in private knowledge:** Composable retrieval pipeline (rewrite → hybrid search → neighbor expand → cross-encoder rerank → LLM) with multi-tenant isolation and ACL filters at vector search time.

- **Safe tool calling:** Connectors (Gmail, Drive, Calendar, Notion, Slack, GitHub, Linear, and more) with typed schemas, human approval for sensitive actions, and per-user/tenant audit trails.

- **Arena mode:** One question to multiple specialized agents in parallel, with independent streaming and a final synthesis of merged sources — without mixing document permissions.

- **Product surfaces:** Web console (React / TanStack Start), embeddable Lit widget, mobile/desktop clients, and product landing.

## Technologies

- **AI backend:** Python, FastAPI, Celery, OpenAI (Responses API / embeddings), PydanticAI
- **Data:** PostgreSQL, Qdrant, Redis, MinIO/S3
- **Frontend:** TypeScript, React, TanStack Start, Vercel AI SDK, Tailwind CSS, shadcn/ui
- **Integrations:** Composio, MCP, channels (Telegram and others)
